# 数式検知 & 高校数学 LaTeX 変換 Web アプリケーション

自然文やメモなどの文字列から数式や公式名を自動検知し、LaTeX形式に変換して一覧・プレビュー表示するWebアプリケーションです。
日本の高校数学（数学I・A・II・B・III・C）で学習する主要な公式・記号・演算子を網羅した変換辞書を備えています。

---

## 🚀 主な機能

1. **文字列からの数式自動検知**:
   - 日本語の文章内に含まれる公式名・定理名（例: 「解の公式」「正弦定理」「相加相乗平均」など）
   - 代数方程式や関数式（例: `y = ax^2 + bx + c`、`x^2 - 4x + 3 = 0`）
   - 微積分・極限記号（例: `lim_{x->0} (sin x)/x = 1`、`int_0^1 x^2 dx = 1/3`）
   - ベクトル記法（例: `vec(AB)`、`vec(a)・vec(b) = 0`）
   - 順列・組合せ（例: `10C3`、`nPr`）
   - 明示的なTeX記法（`$...$`, `$$...$$`, `` `...` ``）
2. **高校数学 変換辞書（数I・A・II・B・III・C網羅）**:
   - 高校教育課程の重要公式・定理を網羅。
   - 辞書ビューア機能で全公式を検索・閲覧し、直接入力欄に挿入可能。
3. **LaTeX コード変換 & リアルタイムプレビュー**:
   - KaTeX による高速かつ美麗な数式レンダリング。
   - 各数式の「LaTeXコードコピー」「`$...$` 付きコピー」機能。
   - 検出された全数式の一括コピー機能。
4. **外部サーバ不要（スタンドアロン）**:
   - ブラウザで `index.html` を開くだけで即座に動作します。

---

## 📂 ファイル構成

- `index.html`: Webアプリケーションの画面構造（KaTeX CDN読み込み）
- `style.css`: レスポンシブで洗練されたモダンUIデザイン
- `math_dict.js`: 高校数学公式辞書（数I〜Cの公式群、記号・演算子置換ルール）
- `app.js`: 文字列走査・数式検知エンジン、LaTeX構文変換、UI連携ロジック
- `README.md`: 本説明書

---

## 📖 起動方法

1. フォルダ内の `index.html` をお好みのブラウザ（Google Chrome, Edge, Safari など）でダブルクリックして開きます。
2. サンプルボタン（「数I・A 総合」「数II・B・III 微積分・数列」「ベクトル・確率・複素数」）を押すと、即座に検知と変換の動作を確認できます。
3. ご自身のメモや文章をテキストエリアに入力すると、リアルタイムに数式が抽出・変換されます。

## 📚 網羅されている高校数学のカテゴリ

- **数学I**: 数と式（3乗の展開・因数分解）、2次方程式の解の公式、判別式、平方完成、三角比の相互関係、正弦定理、余弦定理、三角形の面積、ヘロンの公式、データの分析（分散・標準偏差・相関係数）
- **数学A**: 順列・組合せ（`nPr`, `nCr`）、重複組合せ（`nHr`）、条件付き確率、反復試行、チェバ・メネラウスの定理、方べきの定理、ユークリッドの互除法
- **数学II**: 二項定理、解と係数の関係、相加・相乗平均、コーシー・シュワルツの不等式、点と直線の距離、円の方程式、加法定理、2倍角・半角の公式、三角関数の合成、対数の底の変換、導関数の定義、1/6公式
- **数学B**: 等差数列・等比数列（一般項・和）、シグマの計算公式（$k, k^2, k^3$）、階差数列、確率変数の期待値・分散、二項分布、正規分布の標準化、信頼区間
- **数学C**: ベクトルの内積・垂直条件・なす角、2次曲線（楕円・双曲線・放物線の標準形）、複素数平面（極形式・ド・モアブルの定理）
- **数学III**: 極限（$\frac{\sin x}{x} \to 1$, ネイピア数 $e$）、積・商・合成関数・逆関数の微分、置換積分・部分積分、区分求積法、回転体の体積、曲線の長さ
