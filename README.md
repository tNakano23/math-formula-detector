# 数式検知 & LaTeX 変換ツール (PDF・論文コピペ対応)

PDF・論文・規格書などの文書からコピー＆ペーストした際に崩れてしまう数式や記号を自動検知し、綺麗なLaTeX形式に復元・変換するWebアプリケーションです。

---

## 🚀 主な機能・特徴

1. **PDFコピペで崩れた数式の自動復元**:
   - 改行によって分子と分母が縦並びに分裂した分数を自動結合・復元
   - Mathematical Alphanumeric Symbols（数学用イタリック英字・特殊記号）を正規化
   - 表形式（記号・意味・単位）の独立変数行や行頭記号の自動抽出
2. **複数の解釈サジェスト（候補）切替機能**:
   - `CW_LC` や `CW`、`AB` などの表記に対して、文脈に応じた4つの解釈をワンクリックで切り替え可能：
     - 🏷️ **下付き添字 (A_B)**: $C_{W\_LC}$, $C_W$, $f_T$ （工学仕様書・物理式で最も一般的）
     - ✖️ **乗算積 (A·B)**: $C \cdot W$, $A \cdot B$ （2つの変数の積）
     - 🔺 **上付き指数 (A^B)**: $C^{W\_LC}$, $x^2$ （累乗・指数）
     - 🔤 **単一変数 (AB)**: $\mathrm{CW}$ （単一の英字識別子）
3. **実用的なお試し例文内蔵**:
   - 🚢 **船舶規則・表コピペ**: 船級規則（ClassNK）の係数表から改行分数や添字記号を抽出
   - 🌊 **流体・熱力学**: レイノルズ数（縦並び分数）、状態方程式（積と添字）
   - 🤖 **機械学習・統計**: 損失関数（シグマ）、勾配更新式（偏微分記号）
   - 🏗️ **構造・材料力学**: 曲げ応力式（分数）、断面二次モーメント（指数）
4. **ワンクリックLaTeXコピー**:
   - 通常のLaTeXコードコピー
   - `$ ... $` で囲んだインライン形式コピー
   - 検出された全数式の一括コピー
